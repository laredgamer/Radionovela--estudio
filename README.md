# RadioNovela Studio

Aplicación PWA para crear radionovelas y audiolibros dramatizados en español.

## Primera versión (v0.1.0)

El código inicial se entrega en el paquete **RadioNovela-Studio-v0.1.0.zip** asociado a esta conversación. Descomprímelo y súbelo a este repositorio para incorporar la aplicación completa.

## Tecnologías
- React + Vite
- PWA instalable en Android y escritorio
- Importación de TXT, PDF con texto seleccionable y Word DOCX
- Detección de diálogos y asignación de voces del navegador
- Grabación de diálogos, importación de música/efectos y exportación WAV/MP3

## Ejecutar
```bash
npm install
npm run dev
```

## Estado y limitaciones
Esta es una base funcional local. La generación de voz IA descargable requiere integrar un proveedor TTS mediante un backend seguro. Los proyectos exportados como JSON guardan estructura y asignaciones; conserva por separado los audios exportados.

Consulta el README incluido en el ZIP para instrucciones completas y hoja de ruta.
